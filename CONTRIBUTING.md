# Contributing

Thanks for the interest. This is a small skill-based plugin; contributions are welcome.

## Ways to contribute

- **Bug reports / questions** — open an issue describing what you saw and what you expected.
- **Improvements to the coaching content** — the value of the plugin lives in `skills/learning-driven-execution/SKILL.md`, `references/`, and `assets/`. Tighter prompts, clearer examples, sharper coaching moves are all welcome.
- **New trigger examples** — if you find phrases that should activate the skill but currently don't, propose them.

## Editing the skill

The skill is plain Markdown. Keep it short and direct — the SKILL.md is loaded into the model on every trigger, and the `references/` files are pulled in only when needed. Bias the SKILL.md toward router-and-stance content; push detail into `references/`.

When you change content:

1. Read the existing file end-to-end first.
2. Match the existing tone (coach, don't gatekeep; short; concrete examples).
3. Avoid hardcoded names, internal links, or organization-specific references.

## Pull requests

1. Fork the repo, create a topic branch.
2. Make the change.
3. Open a PR with a one-paragraph description of what changed and why.

That's it.
